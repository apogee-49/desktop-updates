# Shots Desktop – Releases

Installer und Update-Dateien der Windows-App **Shots Desktop**. Der Quellcode liegt in einem privaten Repository.

## Installieren

Unter [Releases](../../releases/latest) die Datei `Shots_<Version>_x64-setup.exe` herunterladen und ausführen. Die App aktualisiert sich danach selbst: Beim Start erscheint ein Hinweis, sobald eine neue Version bereitsteht.

Projekte und Medien liegen unter `Dokumente\Shots` und bleiben bei Updates erhalten.
